# Upgrading to v1.0.0

v1.0.0 is the first release of the rebuilt service. It stores the Scenes Composer of each project, exports its manuscript, and runs its AI suggestions through [GenAI](https://github.com/a-novel/service-genai).

## Do I need to act?

**No.** v1 is a rebuild, not an upgrade of v0: it starts a new history with a new API and database schema, and nothing consumed the v0 releases. Its migrations cannot upgrade a v0 database, so deploy it on an empty one, following [Deploying](../../README.md#deploying). The `v0` line takes no further release.
