# Upgrading to v1.0.0

v1.0.0 is the first release of the rebuilt service. It stores the Scenes Composer of each project, exports its manuscript, and runs its AI suggestions through [GenAI](https://github.com/a-novel/service-genai).

## Do I need to act?

**No.** v1 is a rebuild, not an upgrade of v0: it shares no history, endpoints or database schema with v0, and nothing consumed the v0 releases. Deploy it on an empty database, as [Deploying](../../README.md#deploying) describes, because its migrations cannot upgrade a v0 database. The `v0` line takes no further release.
